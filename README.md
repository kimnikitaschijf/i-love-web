# I Love Web – Mijn Digital Garden

Welkom bij **I Love Web** 🌱  
Deze website is een plek waar ik mijn leerervaringen, projecten en aantekeningen van het *We Love Web* hoorcollege deel en verder uitwerk.

## Over de website

**I Love Web** bevat:

- **Learning Journals** – Documenteer mijn leerproces en reflecties.
- **Digital Garden** – Een plek om mijn kennis en ideeën te organiseren en te delen.
- **Projecten** – Mijn projecten die ik tijdens de cursus ontwikkel.
- **Hoorcollege Notes** – Aantekeningen van het *We Love Web* hoorcollege, zodat mijn kennis gedeeld blijft.

## Live demo

Bekijk de website hier: [i-love-web-jgsk.onrender.com](https://i-love-web-jgsk.onrender.com)

## Hoe te gebruiken

Installatie
1.  Download en installeer Node.js.
2. Fork deze repository naar je eigen GitHub-account.
3. Clone de repository naar je laptop.
4. Open de repository in VS code.
5. Open de terminal in de map van je project in VS Code.
6. Installeer de benodigde pakketten door het volgende commando in de terminal uit te voeren: npm install
7. Start de server met het commando: npm start Bekijk je project door de lokale host-link die in de terminal verschijnt te openen in je browser.
